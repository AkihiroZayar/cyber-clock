# Changelog

All notable changes to **Cyber Clock** are documented here.
This project follows [Semantic Versioning](https://semver.org/).

## [1.2.0] — 2026-10-26

- **Installable app (PWA).** Add Cyber Clock to your home screen or desktop; an *Install app* button appears when your browser supports it.
- **Works offline** — the service worker caches the app after the first visit.
- Now hosted on Cloudflare at **https://time.akihirolabs.com** (moved from GitHub Pages).

## [1.1.0] — 2026-09-29

- New app logo in the AkihiroLabs family style (navy base, white symbol, cyan accent): `app-icon.png`, `favicon.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`.
- The page now has a favicon and a home-screen icon.

## [1.0.0] — 2026-09-28

- Split the single-file `index.html` into `index.html`, `css/style.css` and `js/app.js`.
- Added `js/version.js`, `README.md` and `CHANGELOG.md`.
- Repository renamed from `SchoolTest` to `cyber-clock`.
- No feature or behavior changes.
